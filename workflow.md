# Один эпизод → одна правка

Заполните вручную для одного фрагмента. BrandPilot может дать личный архив и образец голоса; SpeakerCopilot — обещание, прогон, сверку и новую версию. Это переносимый шаблон, не автоинтеграция; доступ к проектам не нужен, если у вас есть разрешённые материалы.

## Заполните

```text
Источник и разрешение:
Точный эпизод (версия / время / контекст):
Обещание слушателю → его наблюдаемое действие:
Ограничение роли:
Фрагмент прогона / дословная цитата (таймкод только из источника):
Одна минимальная правка:
Решение автора (принять / изменить / отклонить + почему):
Вопрос для поста / статьи / главы:
```

## Публичный учебный пример

Вымышленный фрагмент: реального участника нет. Ограничение роли: **«На финальном документе должна стоять моя подпись»**.

| Поле | Пример |
|---|---|
| Источник / эпизод | Учебный слайд, один совет; разрешён для упражнения |
| Обещание → действие | Применить делегирование завтра, сохранив ограничение |
| Цитата | «Делегируйте отчёт»; таймкод не дан |
| Одна правка | «Поручите коллеге черновик; проверьте и подпишите финальную версию сами» |
| Решение автора | `[автор выбирает сам]` |
| Вопрос для публикации | Как делегировать работу и сохранить ответственность за итог? |

Проверку ясности проведите отдельно на человеке с подходящей ролью. Время сравните отдельно по исходной и новой записи; не считайте ни одну проверку уже выполненной.
