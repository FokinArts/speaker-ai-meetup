## Установка в Codex

Скопируйте папку нужного навыка в `.agents/skills/<name>/` в корне проекта. Например:

```text
.agents/skills/promise-audit/SKILL.md
```

В запросе вызовите `$promise-audit`, `$voice-pass`, `$pc-second-read` или `$rehearse-the-room` и приложите только нужные материалы. Если устанавливать skill не нужно, скопируйте его `SKILL.md` в начало запроса к чату.

## Примеры вызова

```text
$promise-audit Сопоставь заявку с размеченным транскриптом. Покажи точные цитаты и только имеющиеся таймкоды; отметь неопределённость.

$voice-pass Сверь этот текст с моими образцами. Предложи минимальные правки и три реплики для проверки вслух.

$pc-second-read Слепо оцени обезличенные заявки A и B по критериям ниже. Сначала дай оценки отдельно, затем сравни факты, риски и вопросы для обсуждения комитетом.

$rehearse-the-room Проверь обещание, фрагмент доклада и роль «на финальном документе должна стоять моя подпись». Попробуй выполнить совет пошагово, найди первое место остановки, предложи минимальную правку и отдельно спланируй проверку на человеке и времени записи.
```

Для слепого чтения удалите имена и сведения об авторе до передачи заявки. Навык помогает подготовить обсуждение, но не голосует и не принимает решение за ПК.

## Границы

Для пробы используйте учебные данные. Для рабочих материалов выбирайте среду, в которой разрешено обрабатывать запись и заявки. При работе в облачном чате материалы получит его провайдер.
