# Сценарий чат-бота для упражнения

Этот бот проводит короткую репетицию разговора с автором заявки. Браузерная версия доступна по ссылке на упражнение ниже.

1. Покажи кейс: **«Мы внедрили ИИ в разработку и повысили качество»**.
2. Предложи выбрать один вопрос для следующего шага:
   - «На сколько процентов?»
   - «Какую задачу проверим?»
   - «Какую модель взяли?»
3. После выбора покажи разбор выбранного варианта из [`../challenge.md`](../challenge.md) и предложи участнику вернуться к выбору.
4. В финале спроси, какое свидетельство помогло бы проверить исходное утверждение. Не требуй реальных данных компании или сведений об участниках.

Сценарий тренирует различение сильного проверочного вопроса и вопроса, который пока не проверяет сам тезис. Это учебное упражнение, а не измерение компетентности участника.

## Локальный Telegram-бот (по желанию)

`bot.py` — отдельный вариант этого упражнения на Python 3.10+ без внешних Python-библиотек. При запуске он обращается к Telegram Bot API через long polling. Бота в Telegram нужно создать и настроить самостоятельно; этот репозиторий ничего не создаёт и не развёртывает.

```sh
export TELEGRAM_BOT_TOKEN='токен-бота'
python3 bot.py
```

Либо сохраните токен в локальном файле только с правами владельца (`chmod 600 /path/to/telegram-token`) и задайте `TELEGRAM_BOT_TOKEN_FILE=/path/to/telegram-token`. Не передавайте токен аргументом командной строки и не добавляйте его в Git. Бот не сохраняет сообщения, голоса или идентификаторы на диск; offset long polling живёт только в памяти. Сетевые ошибки, 429 и 5xx повторяются с паузой; постоянные 400/403 пропускают текущее обновление, чтобы очередь продолжилась. В логах нет токена, URL или тела ошибок.

Локальная проверка без токена и сети: `python3 smoke_test.py`.
